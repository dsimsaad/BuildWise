# BuildWise

BuildWise is a web-based Construction Project Management and Cost Analysis System built with **ASP.NET Core MVC**, **C#**, **Entity Framework Core**, and **Microsoft SQL Server**. It helps contractors, builders, project managers, and property owners manage construction projects from a single platform.

The system replaces manual record-keeping with a centralized digital solution, making it easier to manage budgets, workers, materials, project progress, and expenses in real time.

---

## Features

* User authentication and secure login
* Property and project management
* Construction phase and task management
* Budget planning and expense tracking
* Material inventory management
* Worker management and tracking
* Automatic wage calculation
* Financial ledger with automatic transaction logging
* Intelligent project advisor with alerts
* PDF report generation
* Project-specific workspace using session management
* Responsive dashboard with project analytics

## Architecture

The project follows a clean **Multi-Layer Architecture**, separating responsibilities into different layers:

* Presentation Layer (MVC)
* Business Logic Layer (BLL)
* Data Access Layer (DAL)
* Database Layer (SQL Server)

This structure keeps the code modular, maintainable, and scalable.
